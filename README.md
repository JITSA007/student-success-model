# Student Success Predictor

This project uses machine learning to predict whether a student will pass or fail their exams based on their study habits, demographics, and lifestyle factors. 

## About the Data
The model is built using the "Student Exam Performance & Success Dataset" from Kaggle, which contains 100,000 student records and 44 different features. 

## Goal
To build a binary classification model that accurately predicts the `pass_status` of a student, helping to identify those who might need early academic intervention.
